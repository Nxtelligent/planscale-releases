# PlanScale releases

Installers and the update feed for **PlanScale**, a compact Windows app for reading PDF plans and measuring them to scale.

- Download the latest installer from [Releases](https://github.com/Nxtelligent/planscale-releases/releases/latest).
- Installed copies update themselves: click **Update** in the app's toolbar.

Every installer is signed; the app refuses updates that don't match its signing key.
The source code is kept in a private repository.
